## One critical design decision

There are actually **three different projects** we plan to build:

### A. AI cryptocurrency

Primarily a blockchain/token project.

### B. AI marketplace + token

AI services generate real token utility.

### C. AI economy

Humans + AI agents perform verified work and exchange value using the token.

**C is the most ambitious version.**


Below is a **whitepaper-style v0.1** for AIX. I would position it as an **AI utility/economic network first and a cryptocurrency second**. The key design principle is that AIX should reward *verifiable useful contribution*, not simply token holding or artificial activity.

Because AIX would involve AI agents, data, payments and potentially users worldwide, the design should include compliance-by-design. For example, EU AI Act transparency requirements for certain AI systems apply from **2 August 2026**, including requirements around informing people when they interact with AI and machine-readable marking of AI-generated content. # 2. The Problem

The AI economy currently has several structural problems.

### 2.1 Human contribution is undervalued

Millions of people possess useful:

* knowledge
* experiences
* domain expertise
* language skills
* technical knowledge
* evaluation capability

but there is no universal economic infrastructure for converting these contributions into measurable AI value.

### 2.2 AI agents have no native economic identity

An AI agent may perform:

```text
research
coding
security analysis
data processing
customer support
testing
AI evaluation
```

but generally operates through a human/company-controlled account.

AIX introduces:

> **AI-native economic identity.**

### 2.3 AI compute is expensive

GPU owners may have unused capacity while AI companies need compute.

AIX creates a marketplace:

```text
GPU Provider
     ↓
AIX Network
     ↓
AI Consumer
```

### 2.4 AI-generated work is difficult to measure

The fundamental question becomes:

> **How do we know whether an AI agent actually produced something useful?**

This is the problem PoAIC attempts to solve.

# 19. Anti-Sybil System

A user shouldn't be able to create:

```text
1 person
   ↓
10,000 accounts
   ↓
10,000 × rewards
```

Use multiple signals:

### Identity

Optional KYC/KYB for higher-value accounts.

### Device reputation

Detect large clusters of identical devices.

### Behavioural analysis

Identify automated reward farming.

### Contribution history

New accounts have limited earning capacity.

### Stake

High-value validation requires economic commitment.

### Reputation

Trusted participants receive greater task access.

# 21. Anti-Bot System

The goal isn't to block all bots.

**AI agents are the product.**

The objective is to distinguish:

> legitimate AI agents

from

> fraudulent automated reward systems.

This is an important conceptual distinction.

### Example

Legitimate:

```text
Agent → completes task → validated → earns AIX
```

Fraud:

```text
Bot farm → creates 50,000 fake tasks → fake validation → attempts reward extraction
```

Detection can use:

* task similarity
* output similarity
* wallet graph analysis
* timing patterns
* IP/device clustering
* behavioural fingerprints
* reputation anomalies
* validator relationships
* economic graph analysis

# 34. The Strongest Differentiator

I would make this the central statement of the whitepaper:

> **AIX is a protocol for converting verified intelligence, AI work, human expertise, data and computing resources into measurable economic contribution.**

And the fundamental loop becomes:

```text
CONTRIBUTE
     ↓
VERIFY
     ↓
MEASURE
     ↓
REWARD
     ↓
SPEND
     ↓
CONTRIBUTE AGAIN
```

That's much more defensible as a product concept than simply creating a token whose value is *declared* to come from AI.

# 35. Critical Economic Safeguard

One thing I would explicitly **not** put in the whitepaper is:

> "1 AIX = X dollars of AI value."

That creates a difficult economic and potentially regulatory claim.

Instead:

> **AIX is a utility token used to coordinate and compensate participation in the AIX AI economy.**

The network can create demand through actual utility:

```text
More AI services
       ↓
More AIX usage
       ↓
More economic activity
```

but the **market price remains market-determined**.
